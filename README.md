Movies Recommendation System

The Dataset of this Program is apprx 10 years old so the list of movies is also old.

Select/type the movie name in the box and then press Show Recommendation button and then wait few seconds as it will process and suggest you the movie according to the dataset.

I have built this Program using the following library Pandas,NumPy,skit-learn,ast,nltk and pickle.
All these library played a key role in this project.
